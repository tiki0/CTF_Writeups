# CTF_Writeups

## About

Hey, this is where I throw all my CTF writeups.

I try to write these as detailed as possible so I can look back at them later and actually remember what I did. If you're reading this and trying to learn something, cool, hope it helps.

## Format

Most writeups follow this structure:
1. Initial enumeration and recon
2. Finding the vulnerability/exploit chain
3. Getting user access
4. Privilege escalation (if applicable)
5. Post exploitation notes/looking around

I include screenshots where they make sense, code snippets, and my thought process throughout. I do write a lot of fluff though to be honest.
I like to write out everything I tried INCLUDING the various rabbit holes I likely went down, I think that's part of the process and part of the fun (sometimes).

Happy hacking :)
